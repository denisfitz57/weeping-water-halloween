# Goblins and Popcorn Balls

Eighty-five years of Halloween in Weeping Water, Nebraska, told through clippings from the *Weeping Water Republican* and the *Plattsmouth Journal*, 1901–1998.

A static site with no build step: `index.html`, `css/`, `js/`, `data/` and `clips/`.

Reader memories use the same Google Form and sheet as the flood-history site. Halloween chapters file memories under chapter names starting with `hw-` (for example `hw-pranks`, `hw-costumes`), so the two sites' memories stay separate. Approve one by typing `yes` in its Approved cell.

Clippings flagged with a content note (fires, vandalism, harm to children) are set by the `warn` field in `data/clips.json`.

Newspaper scans come from the [Digital Archives of the Weeping Water Public Library](https://weepingwaterne.advantage-preservation.com/).
